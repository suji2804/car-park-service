# Car Park Service

A Spring Boot REST API for parking vehicles, checking parking capacity, and calculating parking charges.

#Requirements

- Java 17. and Gradle 8.0 or higher are required to build and run the application.
## Run locally

From the project directory, start the application with the Gradle wrapper:

```powershell
.\gradlew.bat bootRun
```

The service starts at `http://localhost:8080`.

## Swagger UI

Open http://localhost:8080/swagger-ui/index.html explore and call the API.


## Run tests

```powershell
.\gradlew.bat test
```
